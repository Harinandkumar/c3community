1. Introduction

What is C3 Admin Panel?

The C3 Admin Panel is a private dashboard used by the Creative Coding Community team to manage the public website. From here, you can create events, upload gallery photos, post notices, manage team members, and much more.

Who can use it?

Only team members with valid email addresses can log in. Each member has a role and specific permissions that decide what they can see and do.

Everything you do here is visible to the public website visitors (unless marked as draft). So make sure the content is correct before saving.

2. Login & Roles

How to Login

Open admin-login.html page. You can log in using one of two methods:

  1. Password Login — Enter email and password (only for old admins).
  2. OTP Login — Enter your team email, click "Send OTP", then type the 6-digit code received in your email. This is the recommended method.
The OTP is valid for 5 minutes. If it expires, click "Resend OTP".
Team Roles

Team members have different roles. Each role decides what sections they can see and use:

Role What They Can Do
⭐ Senior Coordinator Manage events, notifications, gallery, categories, certificates, winners.
🔷 Core Member Full access to events, notifications, gallery, categories, nav items.
🟢 Coordinator Can create notifications, upload gallery images, view members.
🔵 Sub-Coordinator Limited access — mostly read-only.
If a menu item is not visible to you, it means your role doesn't have permission for it. Contact the admin team to update your permissions.

3. Dashboard

The Dashboard is the first screen you see after logging in. It shows four quick statistics:

  • Total Members — Number of registered users on the website.
  • Total Events — Number of all events (open + closed).
  • Verified Members — Users who have verified their email.
  • Active Events — Events that are currently open for registration.
These numbers update in real time whenever you add or delete something.

4. Events

How to Create an Event
  1. Click "Events" in the sidebar.
  2. Fill the form at the top of the page:
    • Event Name — Title of the event
    • Image URL — Link to event banner image
    • Date — Event date
    • Location — Venue name
    • Prize — Prize details
    • PDF Link — Link to rules PDF (Google Drive link)
    • Description — Full description
    • Status — Open (registration allowed) or Closed
  3. Click "Create Event".
How to Change Event Status

Click the "Close" or "Open" button in the Actions column to toggle the event status.

How to Delete an Event
  1. Find the event in the table.
  2. Click "Delete" in the Actions column.
  3. Confirm the popup.
Deleting an event will also remove it from all users who joined it. This cannot be undone.

5. Notifications

What are Notifications?

Notifications are the notices shown on the homepage under the "Latest Notices" section. You can post announcements, recruitment notices, results, etc.

How to Send a Notification
  1. Click "Notifications" in the sidebar.
  2. Fill the form:
    • Title — Short heading
    • Message — Full notice text
    • Priority — Normal or Priority (priority notices appear big and highlighted)
    • Badge Type — None / LIVE / NEW / UPCOMING
    • Button 1 & 2 — Optional action buttons (e.g., "Apply Now" link)
  3. Click "Send Notification".
Badge Types Explained
Badge Meaning
🔴 LIVEEvent is happening right now / urgent notice
🟢 NEWRecently posted
🟡 UPCOMINGComing soon
⚪ NoneNormal notice
How to Delete a Notification

Click "Delete" button in the Actions column of the notifications table. Confirm the popup.

6. Gallery

How to Upload an Image
  1. Click "Gallery" in the sidebar.
  2. Enter an Image Title (this becomes the SEO-friendly file name).
  3. Select a Category (events, workshops, etc.).
  4. Choose an image file (max 10MB).
  5. Click "Upload to Cloudinary".
How to Edit Image Title/Category
  1. Find the image in the gallery grid.
  2. Change the title or category in the input fields.
  3. Click "Update".
How to Delete an Image

Click the red "Delete" button below the image. Confirm the popup. The image will be removed from both Cloudinary and the website.

Images are automatically renamed with SEO-friendly names (like event-name-category-c3-community-123456) for better Google ranking.

7. Categories

How to Add a Category
  1. Click "Categories" in the sidebar.
  2. Enter:
    • Name — e.g., "Workshops"
    • Icon — Any emoji (e.g., 💻)
    • Color — Pick a hex color for the badge
  3. Click "Add Category".
Edit or Delete

Each category card has editable fields (name, icon, color) and an Update button. Below it is a Delete button.

You cannot delete a category if any gallery images are using it. First update those images to a different category.

8. Nav Manager

What is Nav Manager?

This lets you add custom links to the website's top navigation bar (e.g., "Apply Now", "Syllabus", "Sponsors").

How to Add a Nav Item
  1. Click "Nav Manager" in the sidebar.
  2. Enter:
    • Item Name — Text shown in menu
    • Link URL — Full URL (https://... or /page.html)
    • Icon — Choose from Font Awesome list
    • Badge Effect — None / LIVE / NEW / UPCOMING
    • Open in — Same Tab or New Tab
  3. Click "Add Nav Item".
How to Edit or Delete

Click the "Edit" button to update (a series of prompts will appear). Click "Delete" to remove.

9. Members

This shows all registered users of the website with their name, email, branch, batch, registration number, and verification status.

Search Users

Type in the search box — it filters users by name, email, or registration number in real time.

Verified Status

A ✅ green checkmark means the user has verified their email. A ❌ red cross means they haven't verified yet.

This section is for viewing and searching user data. For editing permissions or managing users, contact the admin team.

10. Work / Tasks

What is this section?

This shows all tasks assigned to you by the admin team. Each task has a title, description, priority, due date, and status.

Task Status Flow

Every task moves through these stages:

  • ⏳ Pending → Click "Start" to begin working on it
  • 🔄 In Progress → Click "Complete" when done
  • ✅ Completed → Task finished, no further action
Priority Levels
  • 🔴 High — Urgent, do it first
  • 🟡 Medium — Normal priority
  • 🟢 Low — Can be done later
Whenever a new task is assigned to you, you automatically receive an email notification.

11. Certificates

How to Upload a Certificate
  1. Click "Certificates" in the sidebar.
  2. Fill the form:
    • Certificate Title — e.g., "Hackathon 2024 Winner"
    • Event Name — Optional
    • Identifier Type — Roll Number or Registration Number
    • Identifier Value — The actual roll/reg number of the student
    • PDF File — The certificate PDF
  3. Click "Upload Certificate".
How Users Download

Users log in to their dashboard, go to the "Certificates" tab, and they see all certificates matching their roll number or registration number. They can download them directly.

How to Delete a Certificate

Click "Delete" in the Actions column. The PDF is removed from Cloudinary too.

12. Winners Manager

What is Winners Manager?

Winners Manager lets you display winners of past events on the homepage. Each "Section" is a group of winners (e.g., "QUIZ CLASH WINNERS — October 2024").

Step 1: Create a Section
  1. Click "Winners Manager" in the sidebar.
  2. Fill the form:
    • Section Heading — e.g., "QUIZ CLASH WINNERS"
    • Subtitle — e.g., "October 2024" (optional)
    • Show on Homepage — Tick to display publicly
    • Publish Immediately — Tick to go live instantly
  3. Click "Create Section".
Step 2: Add Winners to a Section
  1. Find the section you created.
  2. Click "Add Winner" button.
  3. Fill in:
    • Name — Winner's full name
    • Roll/Regno — Roll or registration number
    • Event Name — Which event they won
    • Rank — 1st / 2nd / 3rd / Special
    • Photo — Winner's picture
  4. Click "Add Winner".
Step 3: Edit a Section ✏️
  1. Find the section header.
  2. Click "Edit Section" button (green).
  3. A modal opens with:
    • Section Heading (editable)
    • Subtitle (editable)
    • Show on Homepage (checkbox)
    • Published (checkbox)
  4. Change what you need and click "Save Changes".
Step 4: Edit a Winner ✏️
  1. Find the winner card inside a section.
  2. Click the yellow "Edit" button on the card.
  3. A modal opens with:
    • Name, Roll/Regno, Event Name (editable)
    • Rank dropdown (1st / 2nd / 3rd / Special)
    • Photo upload (optional — leave empty to keep current)
  4. Change what you need and click "Save Changes".
You don't need to re-upload the photo if you're only changing the name or event. Just leave the photo field empty.
Publish / Unpublish a Section

Click the "📤 Publish" or "📥 Unpublish" button on the section header. Unpublished sections are hidden from the homepage but still visible to you here.

Delete a Winner or Section
  • Delete a winner: Click the red "Delete" button on the winner card. Confirm.
  • Delete a section: Click the red "Delete" button on the section header. Confirm. Warning: This also deletes all winners inside that section.
Deleting a section is permanent. If you only want to hide it temporarily, use "Unpublish" instead.

13. Sections Builder

What is Sections Builder?

Sections Builder lets you create custom sections for the homepage without any coding. You can build sections using drag-and-drop blocks — like heading, paragraph, image, video, button, gallery, and more. Perfect for creating "About Us", "Achievements", "Sponsors", or any custom content section.

This is a permission-based feature. If you don't see "🎨 Sections Builder" in the sidebar, contact the admin team to grant you access.
Step 1: Create a Section
  1. Click "🎨 Sections Builder" in the sidebar.
  2. Click the "+ New Section" button (top-right).
  3. Fill the form:
    • Section Title — Display name (e.g., "Our Achievements")
    • Internal Name — Unique ID (lowercase, no spaces, e.g., "achievements")
    • Description — Short subtitle (optional)
    • Icon — Any emoji (e.g., 🏆)
    • Background — Default / Gradient / Dark / Light
  4. Click "Create Section".
Step 2: Add Blocks

Once the section is created, it opens automatically. From the left palette, click any block to add it to the canvas.

Available block types (14):

Block What It Does
HeadingBig title (H1–H4 sizes, left/center/right align)
SubheadingSmaller heading
ParagraphText content (multi-line, alignment options)
ImageSingle image (upload or URL, optional caption)
VideoYouTube or embedded video
ButtonCall-to-action button (primary / secondary / outline)
GalleryGrid of multiple images (2, 3, or 4 columns)
ListBullet or numbered list
QuoteHighlighted quote with optional author
DividerHorizontal line separator (solid / dashed / dotted)
CardIcon + title + description + link
CTACall-to-action box with heading, text, and button
HTMLRaw HTML (for advanced users)
SpacerEmpty vertical space
You can drag blocks up/down using the ⋮⋮ handle to reorder them. Click the pencil or trash icon to edit/delete a block.
Step 3: Save Changes
  1. Whenever you change something, a "Unsaved changes" bar appears at the bottom.
  2. Click "Save" to save all blocks and section metadata.
  3. A green toast message confirms: ✅ Saved successfully!
If you close the page with unsaved changes, the browser will warn you. Don't forget to click Save!
Step 4: Publish the Section
  1. At the top of the canvas, you'll see three checkboxes:
    • Show on Homepage — Display on the public homepage
    • Show in Navbar — (Reserved for future use)
    • Published — Make it visible to visitors
  2. Tick "Show on Homepage" and "Published".
  3. Click "Save" (bottom bar).
  4. Open the public homepage (index.html) → hard refresh (Ctrl + Shift + R) → your section will appear.
Editing & Deleting
  • Edit section: Click on the section in the left sidebar to reopen it, then modify blocks and save.
  • Delete block: Click the trash icon on any block's header.
  • Delete section: (Not in UI yet — contact admin if you need to delete a section.)
Best Practices
  • Draft first: Keep "Published" unchecked while building. Only publish when ready.
  • Keep it clean: Don't add too many blocks — 5–8 blocks per section is ideal.
  • Mobile check: Always check your section on mobile (gallery blocks become 1 column).
  • Optimize images: Use compressed images (under 500 KB) for faster loading.
  • Consistent style: Use matching icons/colors for a professional look.
Example section idea: "Our Achievements" — Heading + Paragraph + Gallery + 3 Cards + CTA Button. Try it!

14. Chat Manager

What is Chat Manager?

Real-time chat between website visitors and admin team. When a visitor sends a message through the chatbot on the homepage, it appears here for admins to reply.

How to Reply
  1. Click "Chat Manager" in the sidebar (opens in new page).
  2. Left sidebar shows all chat sessions (visitor names + last message time).
  3. Click a session to open the conversation.
  4. Type your reply in the input box and press Enter (or click the send icon).
Replies are delivered to the visitor instantly via Socket.io. If they're online, they'll see it right away.
Filter Sessions

Use the tabs at the top — All, Unread, Open, Resolved — to filter chats.

Mark as Resolved

Click the ✅ checkmark icon in the chat header to mark a conversation as resolved.

15. FAQ — Common Problems

"Permission denied" error

Your role doesn't have permission for that action. Contact the admin team to update your permissions.

"Session expired" or logged out automatically

Your JWT token expired (7-day limit). Please log in again.

Image upload fails
  • Check file size (max 10MB for gallery, 5MB for others).
  • Make sure it's a valid image (jpg, png, webp).
  • Check your internet connection.
OTP not received
  • Check spam/junk folder.
  • Wait 30 seconds, then click "Resend OTP".
  • Verify your email is registered as a team member.
Changes not reflecting on website
  • Refresh the public page (Ctrl + Shift + R for hard refresh).
  • Check if the item is marked as "Published" (not Draft).
  • Wait 30 seconds — some changes may take a moment to propagate.
"Cannot delete category — images are using it"

First change all images in that category to a different one, then delete the category.

Chat messages not appearing
  • Refresh the page.
  • Check your internet — Socket.io needs a stable connection.
  • Try switching tabs — sometimes the connection resumes.
Sections Builder — Section not showing on homepage
  • Check if "Published" checkbox is ticked.
  • Check if "Show on Homepage" checkbox is ticked.
  • Click "Save" in the bottom bar.
  • Hard refresh the homepage (Ctrl + Shift + R).
Sections Builder — Unsaved changes warning

Whenever you edit blocks or section metadata, a yellow "Unsaved changes" bar appears at the bottom. Click "Save" to persist your changes. If you navigate away without saving, the browser will warn you.

If a problem persists, contact the admin team or email creativecodingcommunity.cs@gmail.com.
